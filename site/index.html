01 Ringkasan angka

Angka di bawah adalah hasil pemulihan statis, bukan denominator seluruh permukaan backend.

Baca angka dengan hati-hati. “29 label service” adalah total label unik: 27 operasi gateway student, 1 operasi gateway staff, dan 1 lookup langsung ke /staff. Label adalah operasi di dalam body request, bukan URL terpisah.

02 Apakah ada API publik?

Jawaban dari bukti statis: tidak ada endpoint REST data akademik yang anonim. Hampir semua klien HTTP melampirkan header Authorization — bahkan saat belum login, karena header dibangun dari interpolasi "Bearer " + token, sehingga token kosong tetap menghasilkan Bearer kosong.

Benar-benar tanpa header auth

  • GET /vnext/v1/fitur/1/android — memakai package:http langsung tanpa argumen headers, dipanggil _proceedToUpdateCheck di splash.
  • wss://armada.smartcampus.ugm.ac.id/gps/ws?room=room2 — koneksi dibentuk dari URI saja.

Tanpa sesi aplikasi

  • GET /oauth/authorize — publik by design; otentikasi terjadi di SSO browser.
  • GET /vnext/v1/banners/get_intro?banner_app=1 — dipanggil splash sebelum login (header jadi Bearer kosong).
  • POST /presensivnext/api/signin — tanpa login aplikasi, tetapi memakai password turunan (kandidat F-01).
  • POST /oauth/token — butuh code valid + client secret tertanam.
Konsekuensi praktis. “Bearer kosong” bukan bukti server menerima request tanpa token. Yang bisa dikatakan hanya: klien mengirim header itu. Apakah server menolak, menerima, atau mengabaikannya belum diketahui dan hanya bisa dijawab lewat staging berizin.

04 Temuan keamanan

Enam kandidat dari analisis statis. Tidak satu pun boleh disebut “exploitable” tanpa membuktikan perilaku server pada staging berizin.

Batas klaim. Semua entri berstatus kandidat. Tidak ada eksploitasi, tidak ada data pengguna, tidak ada pengujian ke produksi. Dampak yang ditulis bersifat kondisional — “jika kontrol server lemah”, bukan “terbukti”.

Yang tidak bisa disimpulkan dari dokumen ini

  • Apakah server menerima token, peran, atau identitas yang dikirim klien.
  • Rate limit, idempotensi, TTL token, dan skema pagination penuh.
  • Perilaku respons nyata — termasuk makna status 400 dan pembuangan body pada doscanent.
  • “Tidak ditemukan” berarti tidak teramati pada code path yang dipulihkan; AOT dapat membangun string secara dinamis.
